# سیستم ERP

یک سیستم برنامه‌ریزی منابع سازمانی (Enterprise Resource Planning) ماژولار که با استفاده از ASP.NET Core و Entity Framework Core توسعه داده شده است.

این پروژه در حال توسعه فعال است و به‌صورت مداوم با اضافه شدن ماژول‌های جدید، قابلیت‌های بیشتر و منطق‌های کسب‌وکار بهبود داده می‌شود. هدف این پروژه ساخت یک سیستم ERP کاربردی است که معماری نرم‌افزار واقعی، مدل‌سازی دامنه (Domain Modeling) و فرآیندهای کسب‌وکار را نمایش دهد.

## 🏗 معماری

این پروژه از الگوی معماری Onion Architecture استفاده می‌کند:

```text
                 ┌─────────────────────────┐
                 │           Web           │
                 │     رابط کاربری،           │
                 │     Razor Pages         │
                 └────────────┬────────────┘
                              │
                 ┌────────────▼────────────┐
                 │     Infrastructure      │
                 │ دیتابیس، EF Core، APIها     │
                 └────────────┬────────────┘
                              │
                 ┌────────────▼────────────┐
                 │      Application        │
                 │ سرویس‌ها، Use Caseها،       │
                 │ Interfaceها              │
                 └────────────┬────────────┘ 
                              │
                 ┌────────────▼────────────┐
                 │        Domain           │
                 │ Entityها، Enumها،         │
                 │ قوانین کسب‌وکار              │
                 └─────────────────────────┘
```

این معماری با هدف جداسازی منطق کسب‌وکار از رابط کاربری و زیرساخت طراحی شده است تا نگهداری، تست و توسعه سیستم ساده‌تر شود.
